vercel-file-sorter — End-to-End Flow

How a LINE message travels from user → Gemini → Drive → Google Sheets

1
User sends image or file to LINE bot LINE
Can be a camera photo, screenshot, or PDF file attachment.
Triggers a message event (type = image or file).
↓
2
Bot downloads the file LINE API
Fetches raw bytes from api-data.line.me/v2/bot/message/:id/content.
External images (shared links) are downloaded differently and saved immediately — no confirmation step.
↓
3
Gemini 2.5 Flash classifies and extracts fields Gemini AI
Sends the image as base64 with a Thai business document prompt.
Returns JSON: { category, dealer, date, amount, branch, bill_no }
6 categories: expense · shipping-cost · invoice · slip-bank · recv-pos · etc
Retries 3× on 429/503 errors.
↓
4
Bot sends confirmation quick reply LINE
8 buttons: 6 category options (AI's guess marked ✅) + ✏️ rename + ❌ cancel.
Shows proposed filename: Dealer_Date_Amount฿.jpg
↓
User taps a category — two paths based on category type
A
Sheet-linked category Redis
invoice · recv-pos · shipping-cost
Saves pending state to Redis (5 min TTL).
Replies: "พิมพ์เลข POS/RECV:"
A2
User types RECV number
e.g. RECV 988 or skip
Bot reads Redis state by recv_pending:userId.
A3
Upload to Google Drive Drive
Re-downloads file by messageId.
Resumable upload → correct folder → returns fileId.
A4
Update Google Sheets Sheets
Searches col B for RECV number → finds row → writes hyperlink.
recv-pos: col B + C(branch) + D(dealer)
invoice: col E
shipping-cost: col H
Not found → appends new row.
B
Non-sheet category Drive
expense · slip-bank · etc

No RECV number needed.
Uploads directly to the matching Drive folder.

No Sheets update.
↓
✓
Bot sends success message LINE
✅ บันทึกแล้ว: {category} → {filename}
