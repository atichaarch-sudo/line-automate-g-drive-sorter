3 Approaches — "skip" should still append a row

When the user has no RECV number yet — how should the sheet row look?

A
Blank RECV — append row with Drive link, leave col B empty Simplest
When "skip" is typed, call the existing append logic with recvNo = "".
For recv-pos: col B gets the hyperlink (that's the normal position anyway) + C/D written.
For invoice and shipping-cost: col B is blank, E or H gets the hyperlink.

B
Placeholder RECV — put "รอเลข" in col B so the row is findable Recommended
Same as A, but col B gets "รอเลข" (Thai for "waiting for number") instead of blank.
Easy to filter/search for unfilled rows. For recv-pos, col B hyperlink display text becomes "รอเลข".
For invoice/shipping-cost, B is the plain text "รอเลข", the hyperlink goes in E or H.

C
Auto-generated temp ID — bot assigns TMPYYMM-001 as placeholder
Bot generates a unique temporary ID (e.g. TMP2605-001) and uses it as the RECV number.
Appends the row with this ID in col B. User can replace it manually when the real RECV arrives.
